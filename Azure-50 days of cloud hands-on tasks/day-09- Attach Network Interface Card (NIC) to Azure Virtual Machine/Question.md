# Day 09 – Attach Network Interface (NIC) to Azure VM

## Task

The Nautilus DevOps team is migrating services to Azure using an incremental approach for better control and optimization.

### Existing Resources

- Virtual Machine: **datacenter-vm**
- Network Interface: **datacenter-nic**
- Region: **West US**

### Requirement

Attach the existing network interface **datacenter-nic** to the virtual machine **datacenter-vm**.
Ensure that:
- The NIC status is **Attached**
- The VM initialization is completed before submission
