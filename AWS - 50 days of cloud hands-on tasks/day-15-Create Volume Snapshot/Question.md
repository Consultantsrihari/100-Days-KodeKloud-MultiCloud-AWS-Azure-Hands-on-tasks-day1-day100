# Day 15: Create Volume Snapshot

The Nautilus DevOps team is preparing automated backup strategies for important
data stored on AWS EBS volumes.

An EBS volume named **xfusion-vol** already exists in the **us-east-1** region.

---

## Task Requirements

1. Create a snapshot of the existing EBS volume.
2. Snapshot name must be **xfusion-vol-ss**.
3. Snapshot description must be **xfusion Snapshot**.
4. Ensure the snapshot status is **completed** before submitting the task.

---

## Region
- us-east-1
