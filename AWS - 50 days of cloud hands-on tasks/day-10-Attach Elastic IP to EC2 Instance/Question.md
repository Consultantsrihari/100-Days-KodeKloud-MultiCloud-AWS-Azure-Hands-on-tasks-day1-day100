# Day 10 – Attach Elastic IP to EC2 Instance

## Task

The Nautilus DevOps team is breaking down the AWS migration into smaller tasks to improve control, reduce risk, and optimize resources.

There is:
- An EC2 instance named **xfusion-ec2**
- An Elastic IP named **xfusion-ec2-eip**

Both resources exist in the **us-east-1** region.

### Requirement

Attach the **xfusion-ec2-eip** Elastic IP to the **xfusion-ec2** EC2 instance.
