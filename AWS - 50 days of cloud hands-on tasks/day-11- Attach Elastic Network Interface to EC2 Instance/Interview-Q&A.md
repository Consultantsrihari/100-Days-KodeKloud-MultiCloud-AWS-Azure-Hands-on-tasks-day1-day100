# Elastic Network Interface (ENI) Interview Questions

### Q1: Why use AWS Console first?
To visually understand resource relationships and reduce mistakes.

### Q2: Why automate after console?
Automation ensures repeatability, speed, and consistency.

### Q3: What is device index?
Defines the network interface order (eth0 = index 0).

### Q4: Can ENI be attached while instance is running?
Yes, ENIs can be attached to a running instance.

### Q5: Can ENIs be detached?
Yes, ENIs can be detached and reattached within the same AZ.
