# Day 07 — Change EC2 Instance Type

## Task
Change the instance type for the instance named `devops-ec2` from `t2.micro` to `t2.nano`.

**Important:** Ensure the Status check is completed (not in Initializing state) before making changes.

## Acceptance criteria
1) The instance type for `devops-ec2` is changed to `t2.nano`.
2) The instance is in the `running` state after the change and passes status checks.
