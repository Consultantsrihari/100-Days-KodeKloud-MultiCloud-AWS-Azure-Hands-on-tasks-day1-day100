# Day 05 — Create an EBS Volume (AWS CLI / Console)

## Task
Create an EBS volume with the following requirements:

- **Name**: devops-volume
- **Volume type**: gp3
- **Size**: 2 GiB

## Acceptance criteria
- A volume exists with the **Name** tag `devops-volume`.
- The volume type is `gp3` and size is `2` GiB.
- Provide the AWS CLI command(s) used and (optionally) a short script to automate creation.
