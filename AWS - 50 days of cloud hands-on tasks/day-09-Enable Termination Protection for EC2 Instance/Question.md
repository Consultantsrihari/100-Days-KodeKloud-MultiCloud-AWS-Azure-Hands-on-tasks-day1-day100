# Day 09 – Enable Termination Protection for EC2

## Task

As XYZ DevOps team created one EC2 instance where they forgot to enable **termination protection**, which is required for this instance.

There is an EC2 instance named **devops-ec2** in the **us-east-1** region.

### Requirement

Enable **Termination Protection** for the given EC2 instance to prevent accidental deletion.
